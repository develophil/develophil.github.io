1. 개요

develophil(이하 "회사")은 피아노리 앱(이하 "서비스") 운영과 관련하여 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 회사가 수집하는 개인정보의 항목, 수집 목적, 보관 기간 및 처리 방법을 안내합니다.

6. 마이크(오디오) 정보의 처리

서비스는 연주 음정을 인식하기 위해 기기의 마이크를 사용합니다. 마이크로 입력된 오디오는 기기 안에서 실시간으로 처리되어 음 높이 판별에만 사용되며, 회사 서버나 외부로 전송·저장되지 않습니다.

자유 연주 화면의 ‘녹음’은 오디오를 저장하는 기능이 아닙니다. 이용자가 누른 건반의 순서와 시각만 기기 메모리에 담았다가 다시 들려주는 것이며, 오디오 파일은 만들어지지도 저장되지도 않습니다.

7. 광고 (Google AdMob)

서비스는 원격 설정으로 광고가 활성화된 무료 이용자에게 학습 결과 화면 하단의 Google AdMob 배너 광고를 표시할 수 있습니다. 기본 학습, 자유 연주와 음성챌린지는 광고 시청 여부와 관계없이 계속 이용할 수 있습니다. 어린이가 이용하는 서비스임을 고려하여 다음과 같이 설정하고 있습니다.

  • 아동 대상 처리(Tag for Child-Directed Treatment)를 적용하고, 전체이용가(G) 등급 광고만 표시합니다.
  • 맞춤(개인화) 광고와 리마케팅은 비활성화되며, Android 광고 ID와 Privacy Sandbox의 광고 관심사·기여도 권한을 매니페스트에서 제거했습니다.
  • AdMob SDK가 광고 제공 과정에서 자동으로 처리할 수 있는 정보: IP 주소(대략적 위치 추정), 광고 상호작용 기록(노출·탭 등), 오류 진단 정보, 앱 세트 ID(App Set ID)
  • 앱 자체 사용 분석은 현재 꺼져 있으며, AdMob의 광고 제공·진단 처리는 이와 별개입니다.

Google의 개인정보 처리에 대한 자세한 내용은 Google 개인정보처리방침을 참고해 주세요.

8. 결제 정보

현재 버전의 서비스는 인앱 결제 기능이 꺼져 있어 유료 상품을 판매하지 않으며, 결제 수단 정보를 일절 수집하지 않습니다. 결제는 전적으로 Google Play가 처리하며 회사는 어떠한 결제 정보도 보관하지 않습니다. 향후 유료 상품을 활성화하는 경우 본 방침을 먼저 개정하고 앱 내에서 안내합니다.

9. 아동의 개인정보 보호

서비스는 어린이의 피아노 학습을 돕는 앱입니다. 만 14세 미만 아동이 소셜 로그인(개인정보 수집이 수반되는 기능)을 이용하는 경우, 법정대리인(보호자)의 동의가 필요합니다.

만 14세 미만 아동은 소셜 로그인 없이 로컬 기기에서만 학습 기능을 이용하는 것을 권장합니다.

앱의 산수 문제와 부모 PIN은 아이가 부모 전용 설정을 쉽게 열지 못하게 하는 장치이며, 그 자체를 법률상 법정대리인 동의로 간주하지 않습니다. 보호자가 선택 로그인을 시작할 때에는 별도의 동의 화면에서 처리 항목·목적·보유·삭제·국외 클라우드 저장 안내를 확인하고, 법정대리인 또는 동의 권한이 있는 보호자임과 개인정보 처리 동의를 각각 표시해야 합니다. 동의 버전과 서버 기록 시각은 로그인 계정에 연결하여 저장합니다. 동의하지 않아도 모든 로컬 학습 기능을 이용할 수 있으며, 랭킹과 클라우드 백업만 사용할 수 없습니다.

현재 절차는 앱 안에서 보호자가 직접 확인하고 동의했다는 기록을 남기는 방식입니다. 휴대전화 본인확인·신용카드·서면 확인 같은 강화된 법정대리인 확인 수단이 필요한지는 출시 국가의 법령과 외부 법무 검토 결과에 따라 보완합니다.

12. English summary

Pianori is a children's piano learning app. A child's profile name, parent PIN, and local learning progress stay on the device. Microphone audio is processed on-device for pitch detection and is neither uploaded nor saved as an audio file. Usage analytics are disabled in this version.

Sign-in is optional. Google sign-in may store an email address and provider identifiers in Supabase Auth. Kakao sign-in stores the Kakao member number, nickname, an internal synthetic email, and a Supabase user ID; it does not request the user's real Kakao email. Signed-in users may store a non-identifying ranking nickname, learning statistics, and a parent-initiated cloud backup. Before optional sign-in, a parent or authorized guardian must review the data notice and explicitly confirm both their authority and consent. The consent notice version and server timestamp are retained with the account. Local learning remains available without consent.

AdMob is configured for child-directed, G-rated, non-personalized ads. The Android advertising ID permission is removed, but Google Mobile Ads may process IP address, ad interactions, diagnostics, and App Set ID. See the Korean sections above for the full current disclosure. Contact develophil.apps@gmail.com for privacy requests.
